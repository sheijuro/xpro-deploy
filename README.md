# 🛡️ xpro-secure-vpn | Advanced 3x-ui Deploy

Ультимативный bash-скрипт для максимально скрытной, безопасной и автоматизированной установки VPN-панели [3x-ui](https://github.com/MHSanaei/3x-ui) на Linux-серверах (Debian / Ubuntu).

Архитектура построена на базе Nginx Reverse Proxy и SNI-маршрутизации. Весь внешний трафик сервера идет строго через зашифрованный порт 443, а сервер маскируется под легитимный веб-сайт, защищаясь от активного сканирования и систем DPI (ТСПУ).

## 🚀 Ключевые особенности архитектуры

* **Полная невидимость (Loopback Only):** Панель 3x-ui, страницы подписок, Inbound-узлы (gRPC/XHTTP) и дашборд статистики спрятаны на внутреннем интерфейсе `127.0.0.1`. Наружу открыты только базовые порты (SSH, 80, 443).
* **SNI-Маршрутизация (Nginx Stream):** Nginx принимает весь трафик и перенаправляет VPN-пакеты напрямую в Xray по SNI. Любые обращения по прямому IP-адресу без указания домена сбрасываются (`return 444`), защищая сервер от сканеров.
* **GeoIP & Whitelist для админок:** Доступ к панели управления 3x-ui и веб-дашборду разрешен только с IP-адресов РФ (RU) или из явно заданного "белого списка". Остальным странам доступ закрыт. При этом VPN-подключения и обновление подписок доступны по всему миру без ограничений.
* **Встроенный Fail2ban и веб-дашборд:** Автоматическая защита от брутфорса и DDoS-атак на базовом уровне. Управление и статистика выведены в удобный дашборд с темной темой, спрятанный за уникальным секретным путем и Basic Auth авторизацией.
* **Anti-Probing (Фейк-сайт):** Скрипт автоматически скачивает и разворачивает один из 10 случайных HTML-шаблонов лендингов для правдоподобной маскировки основного домена.
* **Strict uTLS Fingerprint:** Во всех генерируемых JSON-конфигурациях Inbounds принудительно задается отпечаток `firefox` для максимальной защиты от эвристического анализа пакетов.

## ⚙️ Установка

Для установки выполните в терминале сервера (под root):

```bash
wget -O x-ui-custom.sh [https://raw.githubusercontent.com/sheijuro/xpro-secure-vpn/main/x-ui-custom.sh](https://raw.githubusercontent.com/sheijuro/xpro-secure-vpn/main/x-ui-custom.sh)
sudo bash x-ui-custom.sh

🛠 Использование (xpro)

После успешной первоначальной настройки скрипт автоматически интегрируется в систему как самостоятельная утилита. В дальнейшем для вызова интерактивного меню управления достаточно ввести короткую команду из любой директории:
Bash

sudo xpro

Доступные опции меню:

    [1] Установка ядра, Nginx, SSL, UFW и БД с нуля

    [2] Добавить новое подключение (VLESS / Trojan / SS-2022)

    [3] Изменить существующее подключение (смена протокола/транспорта)

    [4] Управление Fail2ban и дашбордом

    [5] Управление GeoIP-защитой и Whitelist-адресами

    [6] Полное удаление комплекса
