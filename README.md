# 🛡️ xpro-secure-vpn (3x-ui Custom Deploy)

Профессиональный bash-скрипт-комбайн для максимально скрытной и безопасной установки VPN-панели [3x-ui](https://github.com/MHSanaei/3x-ui) на Debian. 

Архитектура построена на базе Nginx Reverse Proxy и SNI-маршрутизации. Весь внешний трафик сервера идет строго через HTTPS (порт 443), сервер маскируется под легитимный веб-сайт, защищаясь от активного сканирования и систем DPI (ТСПУ).

## 🚀 Ключевые особенности архитектуры

* **Тотальная изоляция (Loopback Only):** Панель 3x-ui, страницы подписок, Inbound-узлы (gRPC/XHTTP) и дашборд Fail2ban прослушивают строго внутренний интерфейс `127.0.0.1`.
* **SNI-Маршрутизация на 443 порту:** Nginx принимает весь трафик в блоке `stream`. VPN-трафик маршрутизируется по SNI напрямую в Xray. Обращения по прямому IP-адресу без указания домена сбрасываются (`return 444`).
* **GeoIP & Whitelist защита админок:** Доступ к панели 3x-ui и веб-дашборду Fail2ban разрешен только с IP-адресов РФ (RU) или из явно заданного "белого списка" (Whitelist). Остальным возвращается обрыв соединения. VPN-подключения и получение подписки при этом доступны для всего мира.
* **Скрытый веб-дашборд Fail2ban:** Управление и статистика фаервола выведены в удобный дашборд с темной темой, который спрятан за уникальным сгенерированным секретным путем и дополнительной Basic Auth авторизацией.
* **Anti-Probing (Фейк-сайт):** Скрипт автоматически скачивает и разворачивает один из 10 случайных HTML-шаблонов лендингов или блогов для маскировки основного домена.
* **Strict uTLS Fingerprint:** Во всех генерируемых JSON-конфигурациях Inbounds принудительно задается отпечаток `firefox` для повышения устойчивости к анализу.

## ⚙️ Установка и использование

Для установки выполните в терминале сервера (под root):

```bash
wget -O x-ui-custom.sh [https://raw.githubusercontent.com/sheijuro/xpro-secure-vpn/main/x-ui-custom.sh](https://raw.githubusercontent.com/sheijuro/xpro-secure-vpn/main/x-ui-custom.sh)
sudo bash x-ui-custom.sh
