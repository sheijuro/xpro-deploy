# 🚀 xpro — Secure VPN Deploy

**Русский** | [English](README.en.md)

![version](https://img.shields.io/badge/version-1.4.1-blue) ![platform](https://img.shields.io/badge/Debian%20%7C%20Ubuntu-supported-success)

Интерактивный bash-скрипт для установки и управления [3x-ui](https://github.com/MHSanaei/3x-ui) на Debian и Ubuntu.

Весь внешний трафик идёт через один порт — 443. Nginx разводит его по SNI и по пути, а панель, подписка и все подключения слушают только `127.0.0.1`.



## ⚡ Установка

```bash
wget -4 -O xpro.sh https://raw.githubusercontent.com/sheijuro/xpro-deploy/main/xpro.sh && sudo bash xpro.sh
```

После первого запуска меню вызывается из любого места:

```bash
sudo xpro
```

Язык интерфейса (русский или английский) выбирается при первом запуске, поменять его можно в меню: Настройки сервера → Язык / Language.

## ✨ Возможности

- 🔒 **Один порт наружу.** Открыты только SSH, 80 и 443. Порты подключений недоступны извне даже при выключенном фаерволе.
- 🧩 **Гибкие подключения.** VLESS и Trojan с TCP, gRPC или XHTTP поверх Reality; TCP с собственным TLS-сертификатом; VLESS, Trojan и Shadowsocks с WebSocket, gRPC или XHTTP через TLS на основном домене.
- ➕ **Сколько угодно подключений.** Добавление, изменение и удаление из меню, без ручной правки Nginx.
- 🔗 **Панель и подписка без портов в адресе.** Только HTTPS по секретному пути: `https://домен/секретный-путь/`.
- ✅ **Проверка доступности.** После установки скрипт сам проверяет панель, дашборд и подписку — напрямую и через Nginx — и показывает, что работает, а что нет.
- 🚀 **Быстрая загрузка 3x-ui.** При медленном GitHub скрипт переключается на зеркала и продолжает с того же места. Файл с зеркала принимается только при совпадении контрольной суммы SHA-256 с той, что публикует GitHub.
- 📜 **Сертификаты Let's Encrypt** с автоматическим продлением.
- 🎭 **Сайт-заглушка.** Одна из десяти встроенных страниц со случайным названием сайта; ничего не скачивается из интернета. Меняется из меню, можно поставить и свой HTML.
- 👥 **Управление клиентами из терминала.** Добавление и удаление клиентов без захода в веб-панель.
- 🔄 **Безопасные обновления.** Скрипт, пакеты системы и панель обновляются из меню, данные не затрагиваются.
- 🛡️ **Fail2ban.** Защита SSH и сайта; порт 443 не банится никогда, чтобы не задеть VPN-клиентов. Ставится с веб-дашбордом или без него.
- 📊 **Дашборд Fail2ban.** Статистика банов в стиле OLED Black по секретному пути, без отдельного открытого порта.
- 🌍 **GeoIP-защита и whitelist.** Панель и дашборд открываются только из разрешённой страны и с доверенных адресов. VPN и подписки доступны из любой страны.
- 🧯 **Защита от ошибок.** Необратимые действия требуют набрать слово `yes`; второй одновременный запуск меню блокируется.
- 🏳️ **Названия с флагами.** По стране подставляется эмодзи-флаг: `🇫🇮 Финляндия`.
- 🌐 **Два языка.** Интерфейс на русском и английском.
- ⌨️ **Команда `xpro`.** Скрипт сам устанавливается в систему при первом запуске.

## 📋 Требования

- 🖥️ Debian 12/13 или Ubuntu 22.04/24.04/26.04, доступ root
- 🌐 Два домена (или поддомена) с A-записями на сервер: основной и для Reality
- ➕ По одному дополнительному домену на каждое следующее подключение Reality или TCP+TLS
- 📡 Подключение к серверу по IPv4 — IPv6 при установке отключается

| Пункт | Действие |
|---|---|
| 1️⃣ | 🔐 Показать доступы: ссылки на панель, дашборд и подписку, список подключений, сохранённые логины и пароли |

| 4️⃣ | 📊 Статус служб: Nginx, 3x-ui, Fail2ban, UFW, открытые порты, сертификаты и проверка доступности |
| 5️⃣ | 🔄 Обновления: сам скрипт, пакеты системы, панель 3x-ui, база GeoIP |

До установки 3x-ui пункт 1 — «Установить 3x-ui с нуля», а пункт 2 скрыт.

## 🔌 Типы подключений

| Транспорт | Защита | Протоколы | Нужен свой домен |
|---|---|---|---|
| TCP, gRPC, XHTTP | Reality | VLESS, Trojan | да |
| TCP | TLS (свой сертификат) | VLESS, Trojan | да |
| WebSocket, gRPC, XHTTP | TLS через Nginx | VLESS, Trojan, Shadowsocks | нет |

## 🏗️ Как это устроено

```
Интернет ──443──> Nginx (stream, SNI)
    ├─ домен подключения Reality / TCP+TLS ──> 127.0.0.1:<порт>  (Xray)
    └─ основной домен                      ──> Nginx HTTPS
          ├─ /секрет/  → панель 3x-ui          (GeoIP)
          ├─ /секрет/  → дашборд Fail2ban      (GeoIP)
          ├─ /секрет/  → подписка
          ├─ /путь     → подключения WebSocket / gRPC / XHTTP
          └─ /         → сайт-заглушка
```

GeoIP-проверка стоит только на панели и дашборде. Подписки и VPN-подключения она не затрагивает.

## ⚠️ Важно

- 🗑️ Переустановка и полное удаление стирают панель и базу со всеми клиентами. Оба действия требуют набрать слово `yes`; при переустановке копия базы сохраняется в `/root/`.
- 🌍 При включённой GeoIP-защите панель не откроется из другой страны, если вашего IP нет в whitelist. Отключить защиту можно по SSH: `sudo xpro` → Настройки сервера → GeoIP.
- 🔑 Логины и пароли, сохранённые при установке, лежат в `/root/xpro-summary.txt` и показываются пунктом 1. Пароли по умолчанию скрыты звёздочками.
- 🧹 После смены заглушки браузер может показывать прежнюю страницу из своего кэша. Обновите её через Ctrl+Shift+R или откройте в приватном окне.
- 🔄 Установка от версии 1.0.0 новой версией не распознаётся: файлы на сервере переименованы. Удалите старую установку и поставьте заново.
